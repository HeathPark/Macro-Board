# 가정과 실데이터 검증 현황

## 2026-11-08 클라우드 검증

실제 HTTPS 조회를 시도했지만 클라우드의 제한된 네트워크가 시세·통계 제공처의 연결을 `CONNECT 403`으로 거절했습니다. 따라서 아래 코드는 **사용자 요청에서 가져온 후보이며 실데이터 미검증**입니다. 정상 데이터가 반환되었다고 주장하거나, 근거 없이 코드를 다른 값으로 바꾸지 않았습니다. 네트워크와 선택적 API 키가 준비된 환경에서 수집 결과·종목명을 다시 확인해야 합니다.

조회가 거절된 호스트: `query1.finance.yahoo.com`, `finance.naver.com`, `data.krx.co.kr`, `ecos.bok.or.kr`, `api.stlouisfed.org`. Yahoo 인증·시세용 `query2.finance.yahoo.com`, `fc.yahoo.com` 및 네이버 차트용 `fchart.stock.naver.com`도 사용 라이브러리에 따라 필요할 수 있습니다. 기존 네트워크 허용 목록은 교체하지 않았습니다.

영숫자 신규 ETF는 상장 전 시세가 없을 수 있습니다. 2022년 재현 입력은 당시 존재했던 매크로 지수와 삼성전자·SK하이닉스로 계산하며, 신규 ETF 가격을 역산하거나 채우지 않습니다.

## 금 가격과 대체값

국제 환산가는 `금 선물(달러/트로이온스) × 원/달러 ÷ 31.1035`입니다. `config/universe.yaml`의 `gold.futures_correction_pct`는 국제 금 선물의 현물 근사 보정률(기본 0%)입니다. 이 보정도 검증된 현물 가격을 보장하지 않습니다.

KRX 금현물 실측이 없을 때 TIGER KRX금현물 ETF의 **가격 추이**를 대체값으로 표시합니다. ETF 한 좌 가격은 금 1g 가격이 아니므로 검증된 환산비 없이 ETF 가격으로 김프를 계산하지 않습니다. 이 경우 김프는 `데이터 없음`입니다. 금 선물에는 만기·롤오버 효과가 있습니다.

## 단위와 모델 해석

- Yahoo `^TNX`는 일반적인 제공 관례에 따라 연 수익률 **%**로 취급합니다. 추가로 10으로 나누지 않으며 실제 반환 단위는 네트워크 복구 후 확인해야 합니다. ECOS 금리와 FRED 정책금리·하이일드 스프레드도 % 단위입니다.
- 근원 CPI의 3개월 연율은 `(현재 CPI / 3개월 전 CPI)^4 − 1`입니다. 월별 자료로 연율의 연속 하락을 판정합니다. 관측 기간이나 최신 자료가 부족하면 신호를 확정하지 않습니다. 3개월 연속 하락의 80%는 올림하면 3개월이므로 2개월 하락만으로 물가 조건을 근접으로 표시하지 않습니다. 유가 조건은 별도로 근접 판정할 수 있습니다.
- T1의 120일은 달력일입니다. 두 중앙은행 모두 인상 없음이 확인되어야 충족합니다. 근접은 인상 없는 경과 기간이 임계값의 80% 이상일 때입니다. 결측을 0% 금리로 처리하지 않습니다. 최근 값의 지연과 관측 간 공백의 허용치는 기본 14일이며 `T1.max_stale_days`, `T1.max_gap_days`에서 조정합니다.
- 1W·1M·3M은 달력상 목표일 이전의 가장 가까운 관측 종가와 비교합니다. 1D는 직전 관측 종가, YTD는 이전 연말의 마지막 관측 종가 기준입니다. 목표 시점 자료가 없으면 수익률을 추측하지 않습니다.
- 서로 다른 시장의 휴장일과 거래시간은 다릅니다. 표시된 값은 실시간 체결가가 아닌 마지막 사용 가능한 종가입니다. 통화가 다른 종목의 가격을 직접 합산하지 않습니다.
- 시나리오의 금리·김프 입력은 %p이고 다른 가격 입력은 %입니다. 계산 내부는 소수 수익률이며 복수 요인은 `(1+a)(1+b)−1`로 결합합니다.
- 김프 변화는 요청의 곱셈 근사에 따라 금 원화 수익률과 결합합니다. 현재 김프 수준에 따른 정밀한 상대 변화와는 차이가 있습니다.
- 채권은 수익률 캐리 × 0.5 − 듀레이션 × 금리 변화의 선형 근사입니다. 만기 구조 변화, 볼록성, 세금, 수수료, 분배금과 추적오차는 반영하지 않습니다.
- 개별 미국 주식·VOO의 시나리오 충격은 요청대로 S&P500의 달러 수익률로 근사합니다. 개별 기업 베타는 반영하지 않습니다.
- 퇴직연금의 안전자산 목록은 요청한 ID 목록을 그대로 적용합니다. SOFR·금·주식은 위험자산입니다. 이는 실제 판매사의 규정이나 특정 상품 매매 가능 여부를 검증한 결과가 아닙니다.
- 계좌 금액이 입력되지 않은 상태는 0으로 시작합니다. 실제 보유 금액이나 계좌번호의 예시를 저장하지 않습니다.

## 운영 범위

수집 실패는 항목별 상태로 남기며 다른 데이터 수집과 화면 조회는 계속할 수 있습니다. 데모는 합성 데이터이며 실데이터 저장소와 분리됩니다. 데이터가 없는 과거 재현은 자동으로 수치를 만들어 채우지 않습니다. GitHub 예약 실행은 거래소 휴일을 따로 판별하지 않으며 실제 실행 시각은 지연될 수 있습니다.

## 최신 계획과 수동 항목

`docs/CONTEXT.md`는 사용자가 지정한 투자 프레임워크·계좌 역할·상품 선택·세금 메모를 그대로 기록합니다. 이 문서를 추가하면서 기존의 9개 시나리오 입력을 새 인과 모델로 재설계하지는 않았습니다. 현재 금리·세금·상품 가입 조건을 외부 기관에서 확인한 것으로 해석하지 않습니다.

수동 상품의 연율 금리는 `config/universe.yaml`의 `rate`를 우선 사용합니다. 예금·발행어음·CMA의 캐리는 동일 자산군으로 합치기 전에 상품별로 계산하며, 외화 발행어음은 캐리와 원/달러 변화를 곱셈 결합합니다. 중도 해지, 특판 우대 조건, 금리 재설정, 이자 지급 시점·세금은 반영하지 않습니다. 기존 개인 계획 파일은 보존하며 구형 두 상품 ID도 호환성을 위해 유지합니다.

만기 알림은 한국시간 기준 날짜 차이가 0일부터 설정한 알림 일수 이내인 항목만 표시합니다. 미래 가짜 예시에는 금액이 없습니다. 알림은 달력일 기준이며 재투자나 실제 주문을 자동 실행하지 않습니다.
