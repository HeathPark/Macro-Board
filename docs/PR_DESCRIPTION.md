# 맥락 문서와 최신 계획·수동 상품 금리·만기 알림 반영

계획에서 묶여 있던 현금·예금 상품을 세분화하고, 상품별 연 금리가 실제 시뮬레이션 손익까지 반영되도록 변경합니다. 같은 DEPOSIT 자산군의 특판 발행어음과 은행 예금도 서로 다른 캐리로 평가합니다.

## 변경 요약

- 요청한 원문 그대로 루트 `AGENTS.md`와 `docs/CONTEXT.md` 추가.
- 공개 계획을 최신 계좌별 P1·P2 비중으로 교체. KODEX 200은 위탁 P2, CMA·특판 발행어음·예금은 현금 계좌에 배분.
- `manual`에 CMA·NOTE_1Y·DEPOSIT·USD_NOTE의 연 금리와 통화를 설정. 상품 ID별 충격으로 기여도·계좌·전체 손익 계산. USD_NOTE는 캐리와 환율을 곱셈 결합.
- 금리·듀레이션·방어주 민감도와 퇴직연금 안전자산 분류를 YAML에서 읽도록 정리. 안전자산 목록의 기존 구성 유지.
- 선택적 `private/maturities.csv`의 오늘부터 설정한 30일 이내 만기를 ‘오늘 할 일’에 표시. 정확히 `item,rate,maturity_date` 열만 허용하며 금액 열은 본문 처리 전에 거부. 개인 내용을 캐시·로그에 남기지 않음.
- 계획 탭의 개별 금리 열, 시뮬레이션의 수동 항목별 수익률 표, 가짜 만기 CSV와 한국어 사용법 추가.
- `pytest.ini`로 `pytest -q` 직접 실행 시의 `src` import 오류 해결.

## 검증

- Python 3.11.14에서 `pytest -q`: **71개 통과**. 계산·신호·비중·수집 실패·화면 전환·개인 저장·만기 경계와 형식 검증 포함.
- `python -m src.update --demo`: 성공, 격리된 합성 시계열 38개 생성.
- Chromium: 계획과 수동 금리 시뮬레이션 화면의 상품명·금리 표시 확인. 앱 예외와 자바스크립트 오류 없음.
- 공개 가정과 합성 단위 명목액으로 독립 계산: 시장 변화 0일 때 현금 P1 수익률 2.0375%, P2 2.005%; 환율 +8%일 때 USD_NOTE 10.025%.
- 기존 측정에서 최초 카드 표시 약 3.3초, 캐시 재사용 약 1.6초. 최초 3초 목표는 아직 엄격히 충족하지 못하며 맥북 실측은 미실시.

## 가정과 호환성

기존 개인 계획은 덮어쓰지 않습니다. 공개 계획에서 SHORT_KTB_DIRECT·USD_RP를 제거하고, 기존 개인 파일의 참조를 지원하기 위해 유니버스에만 남깁니다. 만기 알림은 한국시간 달력일 기준 0~30일을 포함하고 지난 만기는 제외합니다. 기간은 YAML에서 조정합니다.

맥락 문서는 투자 프레임워크 기록이며, 기존 9개 시나리오 입력을 새 인과 모델로 재설계하는 작업은 포함하지 않습니다. 금리·특판 조건·세금 메모는 사용자 지정 가정입니다. 원격 main에는 아직 빈 초기 커밋만 있으므로 이 PR에는 기존 대시보드 구현과 이번 변경이 함께 포함됩니다.

## 실데이터 미검증 항목

시장 수집기는 이번 작업에서 변경하지 않습니다. 기존 실제 HTTPS 조회와 공급자 호출은 클라우드 네트워크 정책의 연결 거부로 실패했고 현재 정책도 제공처를 허용하지 않습니다. 수집 경로는 mock과 합성 fixture로 검증했습니다. 다음 항목은 실데이터를 검증한 것으로 간주하면 안 됩니다.

- KRX 후보 코드: `0043B0`, `499660`, `114820`, `451530`, `329750`, `0046A0`, `455030`, `476760`, `0066W0`, `0072R0`, `360750`, `069500`, `161510`, `261220`, `005930`, `000660`.
- 미국 후보 코드: `BRK-B`, `MSFT`, `VOO`. Yahoo 지수·선물·환율 전체와 `^TNX`의 실제 반환 단위.
- ECOS `722Y001`, `817Y002`와 항목코드. FRED `DFEDTARU`, `CPILFESL`, `BAMLH0A0HYM2`. API 키도 현재 미설정.
- KRX 금 99.99_1kg 원/g 공개 표 스키마와 실제 가격. 실제 2022 상반기 재현 입력 전체.
- 사용자가 지정한 CMA·발행어음·예금 금리와 상품 가입·우대 조건, 세금 메모의 현재 적용 여부.

세부 가정과 네트워크 목적지는 `docs/ASSUMPTIONS.md`에 기록했습니다. 과거 재현은 필요한 실제 관측값이 모두 있을 때만 활성화합니다. 금리·김프는 %p, 다른 입력은 %이며, 채권은 캐리와 선형 듀레이션으로 근사합니다.

실제 개인 금액·계좌번호·보유·만기 정보는 이 PR에 포함하지 않습니다.
