# 개인용 매크로·자산배분 대시보드 구축

빈 저장소에 한국어 Streamlit 대시보드와 공개 시장 데이터 수집기를 추가합니다. 오늘의 시장·국면 신호, 관심 종목 수익률, 계좌별 목표 배분, 6개월 시나리오와 선택적 보유 현황을 표시합니다.

개인 금액과 보유 파일은 Git에서 제외한 `private/`에만 저장합니다. 증권사 API는 사용하지 않습니다. 항목별 수집 실패와 선택적 ECOS/FRED 키 누락은 다른 항목을 중단하지 않으며, 데모는 실데이터와 분리합니다. 금 ETF는 가격 추이만 대체하며 금 1g 가격이나 김프를 만들어 내지 않습니다.

## 검증

- Python 3.11.14에서 `python -m pytest -q`: 52개 통과. 계산 공식·신호·비중·실패 격리·데모·화면 전환·개인 저장 경계 포함.
- 의존성 호환성 검사와 `bash -n run.sh` 통과. 실행 스크립트의 반복 설치 방지 및 갱신 실패 후 앱 실행을 격리 환경에서 확인.
- Chromium에서 시장 카드 8개, 탭 전환과 한국어 화면 표시 확인. 자바스크립트 오류와 1280px 가로 넘침 없음.
- 클라우드 측정에서 최초 카드 표시 약 3.3초, 캐시 재사용 접속 약 1.6초. 최초 3초 이내 목표는 이 환경에서 아직 엄격하게 충족하지 못하며 맥북 실측은 미실시.

## 실데이터 미검증 항목

실제 HTTPS 조회와 공급자 호출을 시도했으나 클라우드 네트워크 정책이 연결을 거부했습니다. 수집 경로는 mock과 합성 fixture로 검증했습니다. 다음 항목은 실데이터를 검증한 것으로 간주하면 안 됩니다.

- KRX 후보 코드: `0043B0`, `499660`, `114820`, `451530`, `329750`, `0046A0`, `455030`, `476760`, `0066W0`, `0072R0`, `360750`, `069500`, `161510`, `261220`, `005930`, `000660`.
- 미국 후보 코드: `BRK-B`, `MSFT`, `VOO`. Yahoo 지수·선물·환율 전체와 `^TNX`의 실제 반환 단위.
- ECOS `722Y001`, `817Y002`와 항목코드. FRED `DFEDTARU`, `CPILFESL`, `BAMLH0A0HYM2`. API 키도 현재 미설정.
- KRX 금 99.99_1kg 원/g 공개 표 스키마와 실제 가격. 실제 2022 상반기 재현 입력 전체.

세부 가정과 네트워크 목적지는 `docs/ASSUMPTIONS.md`에 기록했습니다. 과거 재현은 필요한 실제 관측값이 모두 있을 때만 활성화합니다. 금리·김프는 %p, 다른 입력은 %이며, 채권은 캐리와 선형 듀레이션으로 근사합니다.

초기 저장소에 커밋과 원격 브랜치가 없어 비교 기준용 빈 초기 커밋을 `main`에 두고 구현을 `feat/macro-board`에 분리했습니다. GitHub API 네트워크 접근이 허용되어야 이 설명으로 PR을 제출할 수 있습니다.
