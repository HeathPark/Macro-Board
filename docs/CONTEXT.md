# CONTEXT — 투자 프레임워크 요약 (금액 정보 없음)

## 1. 목적
시나리오 기반 자산배분을 계좌별로 실행하고 점검하는 개인 대시보드.
가격 예측이 아니라, 사용자가 입력한 가정을 L1 → L2 → 포트폴리오로 전파해서 보여주는 게 핵심.

## 2. 시나리오 구조
- L1 드라이버(원인): ① 통화정책·금리 ② 물가·경기 ③ AI·반도체 사이클 ④ 지정학·유가
- L2 자산 반응(결과): 환율, 국내주식, 해외주식, 금, 원자재, 채권·현금
- 결과 변수는 L1에서 도출한다. 따로따로 입력하면 앞뒤가 안 맞는 조합이 생긴다.

## 3. 사용자 기본 가정 (2026-11 기준)
- 향후 약 6개월: 인플레이션발 긴축 크래시. 금리 상승, 위험자산 동반 하락 (S1)
- 이후 약 2년: 침체. 분산·분할매수로 자산 증식
- 대조군: S2 디플레 크래시(금리 급락), S3 연착륙 반등

## 4. 국면과 전환
- P1(방어·현금 확보) → P2(장기채·주식 분할 확대)
- 전환은 날짜가 아니라 신호로: T1 긴축 종료, T2 물가·유가 진정, T3 시장 스트레스 정점
- 충족된 신호 1개당 P1→P2 비중 차이의 1/3씩 이동

| 퇴직연금(IRP·DC) | 예금, 채권형 ETF(안전자산), 금·주식 ETF(위험자산 70% 이내) | 선물 ETF, SOFR(위험자산 칸 차지) |

## 6. 세금 규칙 메모
- 일반계좌의 국내 상장 해외·채권·금·원자재 ETF: 매매차익(환차익 포함)에 배당소득세 15.4% + 금융소득종합과세 합산
- 국내 주식형 ETF·국내 개별주(소액주주): 매매차익 비과세
- 해외 직접 주식·ETF: 양도소득세 22% (연 250만 원 공제)
- KRX 금현물: 매매차익 비과세 (실물 인출 시 부가세 10%)
- 개인의 채권 매매차익·외화 원금 환차익: 비과세 (이자만 15.4%)
- 퇴직연금: 위험자산 70% 한도, 레버리지·인버스·선물 ETF 편입 불가

## 7. 상품 결정 사항
- 연금 계좌의 금: SOL 국제금 (국제 시세 추종, 김프 영향 없음)
- 연금·ISA의 달러: TIGER 미국초단기(3개월이하)국채
- 일반 돈으로 사는 금: KRX 금현물 (김프 3% 초과인 달은 ISA에서 SOL 국제금으로 대체)
- 원화 대기자금: 발행어음형 CMA, 퍼스트 발행어음 특판 1년, 은행 정기예금(3·6·12개월)
- 달러 대기자금: 외화 발행어음 수시형
- P2에서 KODEX 200은 ISA가 아니라 위탁에서 매수

## 8. 변경 이력
- 2026-11-08: 최초 작성. 저쿠폰 단기 국고채 → 은행 1년 예금, 달러 RP → 외화 발행어음 수시, 발행어음 1년 4% → 특판 5.1%로 변경.
